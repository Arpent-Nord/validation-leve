1. Quand utiliser l'outil

À la fin d'une journée de levé, avant d'envoyer le fichier aux dessinateurs ou aux intégrateurs. L'outil dessine les lignes selon vos codes, montre ce qui cloche et vous permet de corriger sans Civil 3D.

Votre fichier d'origine n'est jamais modifié : l'outil crée une copie …_modif.txt.

Rien n'est envoyé sur Internet : le fichier est lu dans votre navigateur. L'outil fonctionne aussi hors ligne une fois ouvert une première fois.

2. Fichiers acceptés

AppareilFichierRemarques
Leica CS20 (codage string).txt P,N,E,Z,DFormat de base, avec ou sans en-tête.
Leica CS20 — FRT Export.txt / .frtLes points en double créés par Leica dans les courbes sont reconnus (fermeture ou liaison supplémentaire).
Emlid (Reach / Flow).csv export completFormat adopté : contient la hauteur d'antenne, la précision et la date de chaque point.

Trois façons d'ouvrir un levé : Ouvrir un levé…, glisser-déposer le fichier sur l'écran, ou Coller le contenu copié.

3. Les étapes en bref

  1. Ouvrir le levé. Les lignes apparaissent avec les couleurs des calques ArpentNord.
  2. Ouvrir l'onglet Anomalies : chaque erreur est listée. Touchez-en une pour la voir sur le plan ; ◀ Précédente / Suivante ▶ pour passer de l'une à l'autre.
  3. Corriger : dans la fiche du point (code, description, élévation) ou avec les boutons de la barre d'outils (section 5).
  4. Créer les points des commandes terrain (bouton Créer les points des commandes) et confirmer leur élévation.
  5. Corriger la hauteur d'antenne si besoin (HAUT. ANT.).
  6. Vérifier la numérotation (NUMÉROTER) : elle doit respecter un des deux standards avant l'export.
  7. Exporter : Exporter _modif.txt, Exporter DXF, rapport de levé, puis Envoyer par Outlook…

4. Codes de liaison (string Leica)

La description d'un point s'écrit Code String.Contrôle Attributs, par exemple 526 1.1 = code 526, ligne n° 1, début de ligne.

ContrôleSignification
.1Début de ligne
.2Fermer la figure (retour au premier point)
.3 / .4Début / fin de courbe
.5Point de courbe
.6Cercle par 2 points (diamètre) ou 3 points
.7Continuer une ligne interrompue
(aucun)Point suivant de la ligne

Les contrôles combinés sont acceptés : .1.6, .1.3, .4.2, .4.3.

Un point peut appartenir à plusieurs lignes en joignant les liaisons par _ : 63 1_185 2.

Emlid : le code se met dans Code (ex. 185_1) et le contrôle et la commande dans Description, séparés par des tirets (ex. 1.1-4P).

5. Outils de correction (barre d'outils)

Touchez le bouton, puis les points dans l'ordre demandé (ils sont numérotés en jaune). Chaque correction s'inscrit au journal et peut être annulée.

Affichage

Numéros, Codes, Élév. affichent les étiquettes ; Étendue recadre tout le levé ; Fond ajoute une orthophoto.

6. Commandes de points calculés

Inscrites au terrain sur chacun des points concernés, par exemple 526 1_2PD_1.00. Une commande doit être terminée avant d'en commencer une autre. Elles peuvent aussi être faites au bureau avec le bouton du même nom.

CommandePointsPoint créé
2P2Milieu des 2 points
2PD2À une distance sur l'alignement. Distance sur le 1er point : à partir du 1er vers le 2e. Distance sur le 2e : prolongement au-delà du 2e.
2D2Intersection de 2 distances (négative = à gauche de 1→2)
3PP3Projection perpendiculaire du 3e sur la ligne 1-2
4P4Intersection des droites 1-2 et 3-4
3C3Centre du cercle. Avec .6 (231 1.6_3C), le cercle est aussi dessiné, par exemple pour inscrire le radier d'une grille.

En sélectionnant un point d'une commande, le point à créer apparaît en jaune avant sa création.

Élévation à confirmer : un point calculé est créé à Z = 0. Choisissez dans sa fiche : Z calculé, Z moyen, Z transféré d'un point ou Z manuel. Un avertissement reste affiché tant que ce n'est pas fait.

La fiche d'un point calculé offre aussi le choix Ligne : point seul, ou continuer une des lignes des points de calcul.

7. Hauteur d'antenne / prisme

  1. Touchez HAUT. ANT.
  2. Choisissez les points : touchés sur le plan, cochés dans l'onglet Points (colonne H. ant.), ou une plage de numéros.
  3. La hauteur actuelle est lue dans le fichier (sinon, inscrivez-la) ; inscrivez la bonne hauteur. L'élévation est corrigée de la différence : Z − (bonne hauteur − hauteur actuelle).

La correction est inscrite dans le rapport de levé.

8. Numérotation obligatoire

L'export est bloqué tant que les numéros ne respectent pas un des deux standards ArpentNord. NUMÉROTER renumérote tout le levé en un clic.

StandardFormeExemple fictif
Jour julienAJJJSSNNN : dernier chiffre de l'année, jour de l'année, n° d'arpenteur (01-99), séquence 001-999629401001
DateAAMMJJNNNN : année, mois, jour, séquence2610210001

L'outil affiche le jour julien du levé et celui d'aujourd'hui.

Les points d'implantation et de contrôle (ex. Emlid _stkd) reçoivent le prochain numéro libre, le code 9 et le n° de monument en description. Les points de référence ne sont pas exportés.

9. Annuler, Rétablir, Historique

Annuler défait la dernière correction, puis la précédente, et ainsi de suite.

Rétablir (dans la fiche d'un point modifié : « Rétablir la description », « Rétablir les coordonnées »…) remet ce point à son état du terrain.

Historique liste toutes les corrections : cochez celles à annuler, seulement celles-là. Les corrections qui en dépendent sont cochées avec elles.

11. Fond de plan (orthophoto)

Fond affiche sous le levé une orthophoto du projet (image .jpg, .png ou .tif + son fichier de géoréférence .jgw, .pgw, .tfw) ou une imagerie en ligne. Choisissez le fuseau MTM du projet (8 par défaut).

12. Questions fréquentes

L'outil affiche une ancienne version

Rechargez la page (Ctrl+F5 à l'ordinateur ; sur le téléphone, fermez et rouvrez l'application). La version est indiquée dans l'onglet Options.

Mon fichier n'est pas reconnu

Vérifiez qu'il s'agit d'un des formats de la section 2. Pour Emlid, utilisez l'export complet. Sinon, transmettez le fichier à votre responsable.

Puis-je perdre mon travail ?

Le fichier d'origine n'est jamais touché. Exportez le _modif.txt avant de fermer la page.
